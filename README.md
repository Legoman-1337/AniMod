# AniMod

**AniMod** — это мод для Minecraft (Fabric, версия 1.20.1), который добавляет в игру живого компаньона по имени Аня со своим искусственным интеллектом, экономикой, квестами и системой событий.

## Что делает мод

- **Компаньон Аня** — летающий моб с анимацией (GeckoLib) и набором эмоций/моделей. Умеет летать за игроком, принимать подарки и общаться через чат.
- **AI-чат** — Аня отвечает на сообщения в чате через LLM (с долгой памятью, учётом мира и запасными ответами, если сеть недоступна), плюс набор записанных голосовых реплик.
- **Квесты и карма** — автоматические квесты на сбор предметов (3 уровня сложности), система кармы 0–100, которая меняется от подарков, сообщений и действий игрока.
- **Экономика** — монеты, магазин с апгрейдами и уровнями, «попрошайничество» в чате и проклятия, которые можно купить и снять.
- **Босс-файт** — сражение с самонаводящимися снарядами (можно отбивать мечом), три стадии боссовой музыки.
- **Атмосферные события** — режиссёр событий по «дням»: кислотный дождь, бессонница, особое небо с чёрной дырой, затемнения экрана и другие эффекты.
- **Кастомный контент** — 46 звуковых файлов (голос, шёпот, музыка, эмбиент), свои шейдеры, рендер неба, HUD-счётчик монет.
- **Мини-игра** — отдельная Python-мини-игра (`mini-game/`) в стиле ретро-хоррора: лабиринт от первого лица с фонариком. Найденный в ней код вводится в Minecraft командой `/ani decode`.

## Команды

Основная команда — `/ani`: управление квестами, кармой, монетами, магазином, телепортацией, историей и режимом разработчика (`/ani test on`). Моб призывается через `/summon animod:anya`.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/) ≥ 0.19.5 для Minecraft **1.20.1**.
2. Положите в папку `mods`:
   - [Fabric API](https://modrinth.com/mod/fabric-api) (0.92.x+ для 1.20.1)
   - [GeckoLib](https://modrinth.com/mod/geckolib) (4.8.2 для Fabric 1.20.1)
   - `animod-1.0.0.jar` из этого репозитория
3. (Опционально) Положите `AniResourcePack.zip` в папку `resourcepacks` и включите его — он содержит дополнительные ресурсы мода.

Требуется **Java 17+**.

## Сборка из исходников

```bash
./gradlew build
```

Готовый jar появится в `build/libs/`. Для сборки нужен JDK 25+ (из-за версии Fabric Loom).

## Структура репозитория

- `src/` — исходный код мода (основная логика + клиентская часть)
- `mini-game/` — standalone мини-игра на Python (pygame)
- `animod-1.0.0.jar` — скомпилированный мод
- `AniResourcePack.zip` — ресурспак
